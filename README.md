## 这是什么

「藏经阁」是一个**世界观（世界设定）图书馆**，由两部分组成：

1. **数据目录 `data/`**：由纯 Markdown 文件组成的世界设定词条库。
2. **本地应用**：`藏经阁.exe`（本地服务）+ `藏经阁.html`（网页界面），用来查看、搜索、关联这些词条。

它不是一个云端平台，而是一个「**文件即数据**」的本地应用——每个 `.md` 文件就是一个词条，所在文件夹决定其类型；词条之间只要在正文里互相写到对方的名字，就会自动形成**双向链接**。

当前世界观为 **仙侠（修仙）题材**，发生在大陆 **璇星大陆**。

> 从当前版本起支持**多世界观**：一个「`世界存档\`」容器可存放多个世界观，详见下文「多世界观」。

## 多世界观（世界存档）

从当前版本起，「藏经阁」可以在一个**存档容器**里管理**多个世界观**，像记事本/编辑器那样切换不同的世界观数据。

```
世界观/
└── 世界存档\                  ← 存档容器，装下所有世界观
    ├── .worlds.json           世界观注册表（记录有哪些 + 上次打开的）
    ├── 璇星大陆\              一个世界观 = 一个子文件夹（自带六类目录+标记+纪元表）
    └── （新建的世界观名）\      新建后会多出这样的子文件夹
```

- **每个世界观**＝容器里的一个**子文件夹**，它本身就是一份完整的数据根（含 `人物/势力/物品/地点/事件/设定` 六类文件夹、`.cangjingge.json` 标记、`设定/纪元表.md`）。
- **首次启动**：检测到旧的 `data\` 会自动把它迁移成 `世界存档\璇星大陆\`（项目初始世界观）；之后 `data\` 就不再单独存在。
- **记住上次**：`世界存档\.worlds.json` 记录 `lastActive`，下次打开默认进上次那个世界观。
- **切换/新建**：界面顶部的**世界观下拉框**可切换，旁边的「＋新建」可新建世界观（新建文件夹并自动搭好六类目录）。

> 注：拖入某个世界观文件夹（而非存档容器）启动时，会按旧版「单世界观」方式直接打开它。

## 词条格式（一瞥）

每个词条是一个 `.md` 文件，开头用 YAML frontmatter 存放结构化字段：

```markdown
---
别名: 无衣，洛师妹
纪年: 宏兴25565年
境界: 元婴后期
身份: 剑冢守剑人
---

洛无衣生于剑冢旁的青石村，十九岁以血温养无名剑胚，成青莲剑。
```

- **正文里直接写其他词条的名字**，就会自动产生双向链接（不需要 `[[]]` 等任何标记）。
- 数据就是磁盘上的文件：改文件 = 改数据，反之亦然。

完整的写作与维护规范见 [`AI写词条规范.md`](AI写词条规范.md) 与 [`data/README.md`](data/README.md)。

1. 双击 `藏经阁.exe` 启动本地服务（或以它为数据目录打开）。

3. 想改设定，直接编辑 `data/` 下的 `.md` 文件即可。

## 世界观设定（璇星大陆）

- **纪年**：以「宏兴」为纪元，并存「公元」对照（见 `data/设定/纪元表.md`）。
- **天璇盟**（宏星 0 年）：各大修仙势力统一结成的共治组织，统摄璇星大陆。
- **衰灵元年**（宏兴 25565 年）：灵气枯竭被正式确认，高位修仙者开始闭关坐化。
- **青莲剑**：洛无衣以血温养十九年的本命飞剑，天堕之战后碎为三段。
