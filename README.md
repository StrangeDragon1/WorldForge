## 这是什么

「藏经阁」是一个**世界观（世界设定）图书馆**，核心思想是「**文件即数据**」：

- 每个 `.md` 文件 = 一个**词条**（设定节点）。
- 文件所在的**文件夹**决定词条类型：`人物 / 势力 / 物品 / 地点 / 事件 / 设定`。
- 词条正文里**直接写到别的词条名字**，就会自动形成**双向链接**（不需要任何标记语法）。
- 它不是云端平台，而是你磁盘上真实的文本文件——**改文件 = 改数据**。

当前世界观为 **仙侠（修仙）题材**，发生在大陆 **璇星大陆**（纪元：**宏星**）。

从当前版本起支持**多世界观**：一个「`世界存档\`」容器可以存放并切换多个世界观。

## 快速开始（怎么用）

**方式一：浏览器版**——双击 `藏经阁HTML版.exe`，它会在本地启动服务并自动打开浏览器；之后每次想再看，就再双击它一次。

**方式二：桌面版**——双击 `藏经阁桌面版.exe`，弹出一个原生 WebView2 窗口显示同一套界面。

打开后：
1. 顶部是**世界观切换器**（下拉框 + 「＋新建」）。
2. 左右分栏：左边是**词条列表 / 筛选**，右边是**词条详情**。
3. 想看设定稿，直接编辑 `世界存档\璇星大陆\…\*.md`，刷新即生效。

## 多世界观（世界存档）

从当前版本起，可以在一个**存档容器**里管理**多个世界观**，像记事本编辑器那样切换。

```
世界观/
└── 世界存档\                    ← 存档容器，装下所有世界观
    ├── .worlds.json             世界观注册表（记录有哪些 + 上次打开的）
    ├── 璇星大陆\                一个世界观 = 一个子文件夹（自带六类目录+标记+纪元表）
    └── （新建的世界观名）\        新建后会多出这样的子文件夹
```

- **每个世界观**＝容器里的一个**子文件夹**，它本身就是一份完整的数据根（含六类文件夹、`.cangjingge.json` 标记、`设定/纪元表.md`）。
- **首次启动**：检测到旧版根目录下的 `data/` 会自动迁移为 `世界存档\璇星大陆\`（初始世界观）。
- **记住上次**：`世界存档\.worlds.json` 记录 `lastActive`，下次打开默认进上次那个世界观。
- **切换/新建**：顶部的**世界观下拉框**可切换；点「＋新建」新建世界观（自动搭好六类目录）。

## 词条格式（一瞥）

每个词条是一个 `.md` 文件，开头用 YAML frontmatter 存结构化字段，空一行后是正文：

```markdown
---
境界: 化神后期
性别: 男
身份: 青云宗宗主，天璇盟长老
门派: 青云宗
---

顾云舟，青云宗宗主，化神后期。宏星元年入天璇盟任长老，执掌青云一脉，与天璇盟诸宗共治璇星大陆。

其佩扶摇剑，修青云扶摇诀，御风而行，剑出如长风掠云。
```

- **正文里直接写其他词条的名字**（如「顾云舟」「扶摇剑」「天璇盟」），就会自动产生双向链接。
- 字段的**种类与顺序**由该类型的模板决定（见 `世界存档/璇星大陆/.templates.json`）；没有信息就留空。

完整的写作与维护规范见 [`AI写词条规范.md`](AI写词条规范.md)。

## 功能导览（教程）

### 词条页（默认页）
- **左侧列表**：顶部搜索框按名称/别名/正文搜索；类型下拉可按类筛选；分组标题前的**小三角**可收起/展开一整类；「＋」用该类型默认模板新建词条。
- **列表 / 表格**两种视图切换。
- **右侧详情**：字段表格 + 正文，正文中出现的词条名会自动变成可点击链接；底部有**版本历史**与「编辑」。

### 关系图
- **左侧词条列表**：按类型分组，可收起；顶部**搜索框**可搜并定位某个节点。
- **右侧力导向图**：点一个节点（或左侧词条）→ 该节点套**金色光晕**，与它相关的**连线变金色**、关联节点套**红色光晕**，其余变淡——一眼看清这个节点的关系网。
- 可**拖拽**节点、**滚轮缩放**、点「全览」复位；再点一次已选中的节点会打开该词条。

### 家族
- **左侧搜索框**：输入某个人名 → 只看**这个人的家族**（上下若干代 + 配偶），避免整张图谱过大。
- 谱系树：夫妻居中，**每位家长分别连到自己的孩子**，两家通过夫妻自然相连；点节点打开词条。
- 滚轮缩放 / 拖拽平移 / 「全览」。

### 编年史
- 按各词条的 `纪年` 字段排成**时间轴**（支持 `公元前`、`公元`、自定义纪元如 `宏星`）。
- 纪元顺序由 `设定/纪元表.md` 决定（从上到下 = 时间先后）。

### 地图
- `地图/` 目录放图片，在地图页注册后可**打点**标记地点词条。

### 数据
- 查看数据目录信息、**回收站**（删除的词条可恢复 / 彻底删除）、**词条模板管理**、**操作历史日志**、世界观切换。
