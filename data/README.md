## 项目简介

「藏经阁」是一个**世界观（世界设定）数据仓库**。它不是一套独立软件，而是「藏经阁」应用所读取的**纯数据目录**：

- 每个 `.md` 文件是一个**词条**（entry）。
- 文件所在的**文件夹**决定词条类型。
- 词条头部用 **YAML frontmatter**（`---` 之间的部分）存放结构化字段。

当前世界观为**修仙（仙侠）**题材，发生在 **璇星大陆**。

## 目录结构

```
世界观
├── README.md                 # 本说明文件
├── .cangjingge.json          # 藏经阁数据目录识别配置
├── .maps.json                # 地图注册表（地图与地点标记）
├── .history.log              # 词条操作日志（新建/删除/更新）
├── .versions/                # 每次编辑的版本快照（本地备份）
├── .trash/                   # 回收站（被删除的词条）
│
├── 人物/                     # 角色
├── 物品/                     # 道具 / 法宝
├── 地点/                     # 地点 / 大陆
├── 事件/                     # 事件
├── 势力/                     # 势力 / 组织
├── 设定/                     # 设定（纪年、世界观规则等）
└── 地图/                     # 地图图片素材与打点数据
```

## 词条类型与字段

| 文件夹 | 类型 | 常用字段 |
|---|---|---|
| `人物` | 角色 | 境界 / 年龄 / 性别 / 身份 / 门派 / 生卒年 / 父母 / 亲密关系 |
| `物品` | 道具 | 品阶 / 类型 / 持有者 / 来历 |
| `地点` | 地点 | （按需） |
| `事件` | 事件 | 纪年 |
| `势力` | 势力 | 纪年 / 说明 |
| `设定` | 设定 | （按需） |
| `地图` | 地图素材 | （图片 + `.maps.json` 中注册） |

### 示例

```markdown
---
品阶: 上品灵剑
类型: 冰属性本命剑
持有者: 洛无衣
来历: 剑冢莲池底所得
---

青莲剑通体如凝霜，出鞘时方圆十丈飘雪。

本是剑冢深处一截无名剑胚，被洛无衣以血温养十九年，方成剑形。天堕之战中碎为三段，其中一段下落不明，成了后世许多劫难的引子。
```

## 世界观设定（璇星大陆）

- **纪年**：以「宏兴」为纪元，并存「公元」对照（见 `设定/纪元表.md`）。
- **阁老会**（宏兴 0 年）：各大修仙势力统一建立、用以统治璇星大陆的聚集势力。
- **衰灵元年**（宏兴 25565 年）：灵气枯竭被正式确认，高位修仙者开始闭关坐化。
- **青莲剑**：洛无衣以血温养十九年的本命飞剑，天堕之战后碎为三段，其中一段下落不明。

## 关于「测试·」词条

以 `测试·` 开头的词条是**时间轴排序功能的验证用例**，用于检验不同纪年格式（公元前、公元、宏兴、模糊纪年）的解析与排序。请勿把它们当作正式世界设定删除。
